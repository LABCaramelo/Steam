# Fontes da marca

Direção de Luiz em 2026-10-07: Montserrat, Inter e Covered By Your Grace, todas do Google Fonts.

- Montserrat variável 400–900: títulos e elementos gráficos.
- Inter variável 400–800: corpo, navegação e controles.
- Covered By Your Grace 400: acentos manuscritos em copy já existente.

Arquivos WOFF2 latin/latin-ext obtidos pela API oficial Google Fonts e servidos localmente para manter o funcionamento independente de requests externos no runtime. `manifest.json` registra URL da folha CSS, URLs de cada arquivo e data de obtenção. Licenças OFL originais do repositório google/fonts estão neste diretório.

Os arquivos anteriores de Rama/Saans permanecem no pacote legado; não são carregados pela página atual. A folha anterior está preservada no baseline da auditoria.
